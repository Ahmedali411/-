# شركة إنجاز — موقع الخدمات والمشاريع

موقع عربي باتجاه RTL لشركة إنجاز، مبني باستخدام React وTypeScript وVite. يعرّف الموقع خدمات الشركة ويعرض ألبومات مصنّفة لمجالات التنفيذ.

## التشغيل محليًا

```bash
npm ci
npm run dev
```

للتحقق من النسخة الإنتاجية:

```bash
npm run build
npm run lint
```

## الصفحات

- `/` — الرئيسية ونبذة عن إنجاز.
- `/services` — خدمات المظلات والسواتر والسياجات الأمنية والشبوك والحدادة والهناجر والتشطيبات والترميمات.
- `/projects` — ألبومات مصنّفة مع تصفية حسب الخدمة وعرض الصور بحجم أكبر.

تدعم الروابط `/our-services` و`/our-projects` التحويل إلى المسارات الجديدة.

## الصور

تُستخدم الصور الموجودة في `public/images/` كصور عرض توضيحية إلى حين إضافة صور المشاريع الأصلية. يوضّح الموقع ذلك في صفحة المشاريع، ويمكن استبدال الملفات بالصور الفعلية مع الإبقاء على المسارات أو تعديلها في `src/data.ts`.
